# Tests

This project follows the standard Maven/Spring Boot project structure.

All automated tests are located under:

src/test/java

Specifically:

src/test/java/com/diligent/expensetracker/service/ExpenseServiceTest.java

src/test/java/com/diligent/expensetracker/controller/ExpenseControllerTest.java


Run the complete test suite using:

```bash
mvn test
```

No additional configuration is required.
